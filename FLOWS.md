# ICU Atlas regression and revision checks

Baseline inspected: Overview → Start lesson → Hemodynamic monitoring, with Learn, Visual walkthrough, Bedside case and Skill check. The revised default intentionally changes to the first foundation in a guided route. Keep existing clinical IDs, case order, stored answers, study notes, bookmarks and prior backups compatible.

- Overview, mobile navigation and body-system library: display a next step; search, filter, open each unit, visit lessons, and move forward and back.
- Lesson: read, step/play/pause visual reasoning, reveal worked case, mark studied, bookmark, save note, open sources, take a check, then see results and continue.
- Practice: starting assessment, pathway and mixed sets, unsure/miss → rationale → review queue → different question; cumulative rounds and progress remain accessible.
- Visual atlas: explore all five legacy models; change settings/conditions; pause and follow related lesson.
- Settings and storage: toggle larger text and motion; resume after reopening; export then import an old and a new backup; reject bad backup. Offline reload after initial cache.
- Beginner route: first screen points to cells rather than ICU instrumentation. An ordered path contains every clinical lesson once; foundations use retrievable checks with feedback. Show what is next and why, retain progress without locking access.
- Anatomy and pathophysiology: own searchable section; linked terms have genuine independent pages, normal anatomy, a changed mechanism, bedside observations, sources, neighbors and clinical backlinks. Every clinical lesson has a contextual body/practice bridge. Ethical decisions do not get spurious biological explanations.
- Wikipedia-style detours: follow an inline link, then a related concept, then return to the originating lesson, case or answered question without losing position. Preserve the original unanswered quiz and evidence standards.
- Mechanism animation: compare normal with altered anatomy and physiological consequences, pause/play, manually step, inspect the explanatory captions, and read a motion-free equivalent. Test interactive drawings at desktop and phone widths, not just the lesson index.
- Delivery: rebuild the offline cache and downloadable GitHub package; update the existing private preview only. Do not publish or push to GitHub.
